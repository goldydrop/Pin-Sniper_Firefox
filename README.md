# 🧩 Pin Sniper (Firefox Extension)
**The official browser companion for the Pin Sniper desktop application.**

![Browser](https://img.shields.io/badge/Browser-Firefox-FF7139?style=flat-square&logo=firefox) ![Version](https://img.shields.io/badge/Version-1.0-blue?style=flat-square)

---

### 🚀 What does this do?
This is the companion extension that bridges your Firefox browser with the **[Pin Sniper Desktop App](https://github.com/goldydrop/Pin-Sniper)**. It quietly extracts raw target URLs and media grids from your active tab and routes them directly to your desktop client for high-speed processing.

---

### 🛠️ How to Install in Firefox (Developer Mode)

Since this extension is custom-built and not on the public Firefox Add-ons store, you will need to load it manually:

1. **Download the Extension** > Click the green **Code** button at the top of this page and select **Download ZIP**. Extract the folder to your computer.

2. **Open Firefox Debugging** > Type the following into your Firefox address bar and hit Enter:
